StreamLine Spotlight Future State Journey Map

Persona: Quality-focused streaming subscribers who want to find a great movie or show in minutes, not spend scarce leisure time searching through an overwhelming catalog.

Strategy: Restore brand authority and win back users by prioritizing human-led curation and restoration over mass-market scale.

Value Prop: Spotlight turns StreamLine from a content warehouse into a trusted entertainment guide.
Future State TimelineDiscover -> Trust -> Decide -> Enjoy
1

Curated Discovery

Open Spotlight collection -> See a focused set of trusted options.
User Action

Opens Spotlight instead of browsing endless rows.

Internal State

Relieved that someone has narrowed the choices.

Pain Point Addressed

Choice paralysis from thousands of indistinguishable titles.

2

Confidence Building

Review curated picks -> Understand why each title was selected.
User Action

Reads a short curator rationale for each recommendation.

Internal State

Feels guided instead of pushed by an algorithm.

Pain Point Addressed

Distrust in repetitive recommendations and weak discovery signals.

3

Fast Decision

Pick a title -> Decide within minutes without external research.
User Action

Selects one recommendation with confidence.

Internal State

Certain the choice is worth their limited evening.

Pain Point Addressed

Leaving StreamLine for Google, reviews, friends, or competitors.

4

Enjoyment & Retention

Start watching immediately -> Spend leisure time enjoying content.
User Action

Begins watching instead of continuing to scroll.

Internal State

Satisfied that StreamLine helped create a better evening.

Pain Point Addressed

Wasted entertainment time and abandoned viewing sessions.

Advantage 1

One destination instead of jumping between Google, review sites, and friends.

Advantage 2

Faster confidence by reducing decision time from browsing to choosing.

Advantage 3

Restored authority as StreamLine becomes the trusted recommendation source.
